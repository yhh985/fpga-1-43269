短按 ACA S4，进入后先安静约两秒，再分别说“下一张”“上一张”，每句之后停顿约一秒。
当前只支持语音切图；“下一首/上一首”不属于支持词。

| 屏幕 | 含义与下一步 |
| --- | --- |
| VOICE WAIT | 主板还没有许可，检查两板配套和 UART |
| VOICE CAL | 正在采集背景和填充窗口，保持安静约两秒 |
| VOICE READY | 预热与安静间隔就绪，可以说指令 |
| VOICE HEAR | 前端检测到了说话/正在等待一句话结束 |
| VOICE THINK | 正在模型推理；这一步很短，状态包可能未捕获 |
| VOICE AGAIN | 这句被门控或模型拒绝，提示保留约0.75秒 |
| VOICE QUIET | 尚未满足下一句之前的安静间隔 |
| MIC NO PCM | 编解码器未就绪或没有近期 PCM 采样 |
| VOICE ERROR | 编解码器、前端或模型计算报错 |

有效命令仍在右侧显示 NEXT/PREV。声波有变化但一直停在 READY，优先查声音是否
通过自适应背景门控；HEAR 后 AGAIN，优先查短句门控与模型匹配；一直 HEAR，
优先查句尾背景能否形成安静段。请回报说话时屏幕实际经过哪些状态。
