# 语音短毛刺修复测试版

本次针对真实录音中“已经安静、短毛刺、再次安静、开始说话”的检测缺陷修复，未重新训练模型。
用户最终确认录音顺序为“上一张、下一张”，此前相反的顺序已撤销。

## 改动

保留原来的八帧起声安静要求（256ms）、六帧语句结束停顿（192ms）、至少六帧有效语音、三窗口一致、置信度阈值109和冷却。
仅当某次声音活动本来已满足起声安静要求，却因为有效帧不足六帧而被丢弃时，恢复其开始前已经获得的安静资格。
这避免一次很短的毛刺，使紧跟着的真实指令被起声安静条件错误挡住。
没有资格的毛刺不能凭空获得资格；完整语句后的短停顿仍不放行。

直接将起声安静门槛降至六帧曾在带噪合成回归中引入一次非指令误接受，已撤销该方案。

## 验证与限制

真实录音经整数前端处理后，送入实际 aca_kws_engine RTL：原来零个有效终点，修复后恢复第一个终点，三个窗口均输出“上一张”，符合用户最终标注。
原始输入与补入1.024秒安静的输入均已验证，输出logit与Python整数参考逐位一致。
边界用例验证有资格短毛刺可恢复、无资格短毛刺不可恢复、完整语句不被当作短毛刺；所有背景片段均被模型拒绝。

**该录音的第二句“下一张”仍因间隔不足256ms而被拒绝。本版不能宣称两句都识别成功。**
当前测试建议进入语音模式后等约一秒，每次独立说一句“上一张”或“下一张”，两句间留至少半秒停顿。
这只是当前测试方法，不代表已经解决连续快速指令，也不能替代实板采样。

原合成留出集为406条（116指令、290非指令）。当前判定在无额外噪声及固定幅度250模拟噪声下均未新增非指令误接受。
另有120秒合成风扇声、噪声阶跃、脉冲测试，没有输出语音命令。这不是真实房间的长期误触发率。
模型、音效数字协议、HX码流保持音效时钟偏移修复版；只有ACA语音终点资格逻辑变更。
