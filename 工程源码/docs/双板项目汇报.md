# ACA420 与 HX4S20 双板项目汇报

2026-10-20 后续版本增加了三次语音确认、独立句子窗口、分频带背景门控、32位音效串行链路和音乐曲号显示。本页的历史性能数字不代表新版；以 [当前修复说明](语音误触发与音效噪声修复.md) 和最新 `deliverable/release_manifest.json` 为准。

整理日期：2026-10-19。工程位置：`E:\anlo_project\liantiao`。硬件实现结果取自当前发布清单与两板布局布线报告；本次整理未修改硬件逻辑。

## 项目成果

工程把语音控制、图片浏览和音乐播放连接成双 FPGA 系统：ACA420 采集麦克风并识别“下一张／上一张”，通过 UART 控制 HX4S20 切图；HX 从 SD 卡读取图片和音乐，完成图片处理与 HDMI 输出。音乐送至 ACA 做数字音效，再回到 HX 经 HDMI 播放。

目前交付的是**可上板测试版本**：已有仿真、模型整数对照和布局布线时序证据，尚未完成实体双板、实际 SD 卡及真人独立录音验收。

### ACA：离线语音识别

识别在 FPGA 内运行，无需运行时连接电脑或网络。约 48 kHz 采样降采样至约 8 kHz，经 128 点窗口、63 个 Goertzel 频点、16 路 Mel 特征及整数归一化，形成 48×16 输入。INT8 MLP 为 768→48→3，配合整句端点、分类间隔拒识和约 1.5 秒冷却，输出两条口令或拒绝。

进入语音模式时，HX 先停止音乐，再返回带版本的许可确认；ACA 只有在线且获准后才允许命令生效，重连后重新申请许可。麦克风输入不回放到音响。

开发期留出合成音色回放中，口令正确执行 74/80（92.5%），其中方向错误 2 次、漏判 4 次；其他语句正确拒绝 199/200。开发中已使用过这批回放，**这些数字不能代表未知真人的正确率**。当前没有多人录音盲测数据。

### HX：图片显示和观感缩放

支持 FAT32 卡上的正高度、未压缩 24 位 BMP，宽高分别为 1～1024 像素，等比例适配到 640×480。缩放以适配后的图像为 1 倍，提供 0.5、1、1.5、2 倍：缩小时居中留黑边，放大时居中裁切，屏幕上可见主体尺寸改变。

这是在现有浏览流程中新增缩放操作页。缩放会从 SD 卡重读同一张图，双线缓存插值后写入另一帧缓冲；等整帧写入和显示读者确认后切换，响应速度受读卡与处理时间影响。连续按键合并为最新倍率请求。

### 双板：多首音乐与音效

支持 FAT32 根目录最多 8 首 WAV，按目录扫描顺序播放；格式为 48 kHz、16 位 PCM、单声道或双声道，单文件不超过 64 MiB。支持上一首、下一首、当前曲循环、碎片簇读取，以及与图片共享 SD 卡的仲裁和欠载重缓冲。

音频链路为 `HX SD → 数字音频线 → ACA 音效 → 返回线 → HX HDMI`。当前完成四种音效，**未实现倍速、变调或保留音高的变速**。

## 资源与扩展空间

| 资源 | ACA420 | HX4S20 |
|---|---:|---:|
| LUT | 8439/19600，43.06% | 16842/19600，85.93% |
| 寄存器 | 5029/19600，25.66% | 9801/19600，50.01% |
| BRAM9K | 49/64，76.56% | 55/64，85.94% |
| DSP | 9/29，31.03% | 19/29，65.52% |
| PLL | 1/4 | 3/4 |
| Setup WNS | +1.210 ns | +1.224 ns |
| Hold WNS | +0.054 ns | +0.030 ns |

两板 Setup/Hold TNS 均为 0。上述时序来自 FPGA 内部实现，实际跨板连线仍需实测。

ACA 剩余 11161 LUT、15 块 BRAM 和 20 个 DSP。剩余 BRAM 原始容量约 17 KiB，但不能据此判断总图像存储能力：2026-10-20 核对数据手册确认，器件另外还有独立的 8 MiB 内嵌 SDRAM。当前 ACA 工程尚未接入 SDRAM 控制和显示链路，扩展图片功能需要相应开发。HX 剩余 2758 LUT、9 块 BRAM、10 个 DSP，图像和显示侧资源已较紧张，后续扩展需继续核算缓存及布局布线。详见 [漫画方案评估](交互漫画方案评估.md)。

## 演示和上板安排

1. 下载配套的 `deliverable/aca420_music_voice.bit` 与 `deliverable/hx4s20_music_voice.bit`，按 [音乐接线说明](../MUSIC_上板测试.md) 连接 UART、音频四线及共地。
2. 准备 FAT32 卡与符合规格的 BMP/WAV。可先用 `card_test` 三个不同频率测试音辨认切歌。
3. 检查图片、按键切换、HDMI 音乐与 ACA 四种音效，再演示图片倍率变化。
4. 接入麦克风，进入语音交互，确认音乐静音和许可后测试“下一张／上一张”，退出后检查恢复。
5. 记录真人漏判、误判，连续切歌/缩放、实际卡带宽、音频连线及长时间运行结果，再决定模型和音效的下一轮改进。

HX 短按 K4 循环“图片→亮度→对比度→缩放”；缩放页 K1 放大、K2 缩小、K3 恢复 1 倍；长按 K4 暂停/恢复。ACA S2 下一首、S3 上一首、长按 S3 循环音效，S4 功能键（T4）切换语音模式。其他操作见 [音乐说明](../MUSIC_上板测试.md)、[缩放说明](../ZOOM_上板测试.md) 与 [语音说明](../voice/README_语音上板测试.md)。
