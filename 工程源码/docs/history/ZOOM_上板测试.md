# HX 图片缩放操作

最终工程：`E:\anlo_project\liantiao`。HX 使用 `hx4s20/contest_proj.al`；配套下载文件仍为 `deliverable/hx4s20_music_voice.bit` 和 `deliverable/aca420_music_voice.bit`，当前版本与哈希以 `deliverable/release_manifest.json` 为准。

短按 HX K4，操作页依次为 **图片 → 亮度 → 对比度 → 缩放 → 图片**。缩放页的数码管操作页编号为3：

| 操作 | 作用 |
|---|---|
| 短按 K1 | 放大一档，最大2倍 |
| 短按 K2 | 缩小一档，最小0.5倍 |
| 短按 K3 | 恢复1倍 |
| 短按 K4 | 切到下一操作页 |
| 长按 K4 | 保留原暂停/恢复功能 |

四档为 **0.5、1、1.5、2倍**，数码管倍率编号分别为0、1、2、3。屏幕原有源分辨率后显示 `X0.5`、`X1.0`、`X1.5` 或 `X2.0`，表示已完成绘制的倍率；数码管表示请求倍率，两者在加载期间可能暂时不同。原手动/自动/音乐播放模式独立保留。

倍率相对于图片等比例适配640×480后的大小。0.5倍缩小居中并留黑边，1.5和2倍放大居中，超出屏幕的部分裁切。长宽比不同的图片放大后仍可能有一个方向保留黑边。当前采用双线性插值，不含平移、手势或连续动画。

缩放由HX完成，沿用SD读图、两行缓冲和双帧显存。每次改变倍率会重新从SD卡读取当前图片，将完整新帧写入另一帧缓冲，再交给显示端；加载期间继续显示旧图。连续操作合并为最新请求；暂停期间暂缓新任务，已开始的帧可以完成。倍率保留到换图，复位恢复1倍。无有效SD图片时无法演示此功能，内置测试图不缩放。

## 上板检查

1. 在FAT32卡放入工程支持的BMP文件，先确认普通图片能显示。
2. 从复位后的图片页短按K4三次进入缩放页，观察操作页编号3。
3. K1依次切至1.5、2倍，观察主体变大和边缘被裁切；再按K1保持2倍。
4. K2依次切至1.5、1、0.5倍，观察主体缩小与黑边；再按K2保持0.5倍。
5. K3恢复1倍；快速交替按K1/K2，等待画面与请求倍率一致。
6. 暂停后调整倍率，恢复后确认重画；切换图片、自动播放、音乐和语音切图分别确认原功能。
