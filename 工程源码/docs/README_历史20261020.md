## 接线

| 方向 | ACA420 | HX4S20 |
|---|---|---|
| ACA TX → HX RX | P4 1脚 / E15 | J2 1脚 / FPGA P4 |
| HX TX → ACA RX | P4 2脚 / F13 | J2 2脚 / N4 |
| 共地 | P4 12脚 GND | J2 12脚 GND |

两板分别供电，不连接两板电源。MAX4466 完整麦克风模块：VCC→ACA P4 29脚3.3V，GND→30脚GND；OUT→3.5mm TRS 的 Tip/L，GND→Sleeve，Ring留空，插蓝色IN1。用通断挡确认插头触点，增益从低开始；电源不能接音频插头。
