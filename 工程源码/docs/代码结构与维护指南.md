## 常用命令

从工程根目录打开 PowerShell：

```powershell
Set-Location E:\anlo_project\liantiao
# 公共、ACA、HX、音乐、缩放与构建来源回归
./run_all.ps1
# 加上语音整数对照与相关验证
./voice/run_voice.ps1
# 完整重建、ROM 审计与最终打包，需要已安装 TD
./voice/run_voice.ps1 -Build
```

Python 脚本使用本机 Python，当前安装路径为 `C:/Users/yhh/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`；以下 `$py` 可替换为其他具备依赖的解释器。

```powershell
$py = 'C:/Users/yhh/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
# 刷新实际 TD 输入索引
& $py ./tools/generate_code_inventory.py
# 已有有效构建时，更新说明和发布清单
& $py ./tools/package_music_release.py
# 核对当前交付包
& $py ./verification/check_final_delivery.py
```

## 维护规则

修改 HDL、模型、初始化文件、约束或构建 TCL 后必须重建。`tools/build_verified.py` 对构建前后输入和最终码流、报告做绑定；不能把旧 bit 文件配上新源码交付。只修改说明或文件索引时无需重跑硬件实现，但要重新打包、校验发布清单。

本次整理保留了所有 RTL、模型、约束和 TD 工程路径，只归档带时间戳的 TD 日志；移动记录与 SHA256 保存在 `docs/整理记录.json`。恢复某条日志时按其中 `from`/`to` 对应移动即可。当前 `build_console.log`、资源/时序报告、构建记录及所有回归证据仍在原位置。

外部代码参考及许可证见 `research/zoom_review_20261018` 与 [复审报告](../REVIEW_复审报告.md)；未把外部 RTL 直接复制进当前综合源码。
