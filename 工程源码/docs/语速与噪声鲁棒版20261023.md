# 整句语速归一化与噪声增强测试版

开发入口仍是 `E:\anlo_project\liantiao\development\audio_crc`，基线为
`deliverable/voice_feedback_20261023`，原码流完整保留。

本次不是只增加诊断提示或降低置信度。模型重新训练，加入快慢语速、音量、
平滑频响扰动及波形域背景噪声；网络使用共享时间卷积核，导出为与原 FPGA
MAC 相同的 INT8 768→48→3 矩阵。实际支持词仍为“下一张”“上一张”。

原实现最多只保留最后48个32ms特征帧，慢速说话可能丢失前部。现在使用128帧
环形缓冲，保留整句，按整数最近邻重采样为38/40/42帧三个视图，再进行同向
一致性判定。每个视图尾部保留六个零特征帧。最多允许96帧的整句及尾部安静，
其中实际语音及内部停顿最多90帧，约2.88秒；不代表任意时长都支持。
保留三次同向确认、独立句子、前安静条件、短毛刺处理及自适应分频带门控。

当前实际模型是 `voice/experiments/robust_normalized/model/`，由引擎默认参数直接
引用，编译工具会读取参数绑定对应ROM和配置的哈希。`voice/model/` 保留旧模型
作为配对比较基线，不能运行旧 `sync_model.py` 覆盖当前引擎参数。

## 配对比较

训练/验证/测试按合成说话人隔离。验证集选模型、校准阈值；测试集未用于本轮
选择，但旧项目开发中已有这批合成测试语音的回放，不能称全新的真人盲测。
真实用户录音未参与训练或选阈值。

留出合成测试：406段原始片段（116条口令、290条非口令），每条分别应用三个
特征时间缩放率0.65/1/1.45、两种噪声条件，合计2436个相关回放条件。
语速压力通过特征时间插值实现，保留频率；不是对所有速率重新合成波形。
所有速率之前均补足固定预热静音，避免把启动窗口误算成语速问题。
带噪条件在PCM上加入±500均匀噪声、120/240Hz嗡声，同时将语音增益降至0.7，
之后才通过自适应前端。不能把特征时间缩放等同于真实人的全部语速差异。

总体更少误方向、快慢速和带噪回放改善，但正常无噪声组有退步，且较强噪声下
成功率仍低。这是一版可比较的改进测试码流，不能称已全面解决实板拒识。
历史真实录音仍只恢复第一句“上一张”，第二句仍未通过前安静门控。

120秒连续合成底噪/风扇谐波/音量阶跃/短脉冲回归，15个候选端点、0条命令。
它不是实际房间长期误触发率。

## FPGA 验证与使用

环形缓冲跨边界、短片段、6/90/91帧语音边界和真实录音逐个重放进实际引擎：
30次推理的每个输出 logit 与整数参考完全一致，命令接受及方向一致。
另做语音状态回归、真实双板顶层/UART/音乐回归与最终布局布线时序检查。
双板仿真的存储、PLL、加密HDMI核是测试桩，不能替代实板验收。

地址重采样使用推理前的累加/减法生成48项映射表，避免在MAC地址路径做除法，
与整数最近邻定义保持逐值一致。

ACA 使用本目录的 `aca420_voice_robust.bit`。HX使用与上一语音反馈版相同的
`hx4s20_voice_feedback.bit`，已重新核对源码与码流绑定；若HX已更新过反馈版，
本次只需要更新ACA。进入语音后等待 READY，自然说“下一张”或“上一张”，
说完留一句之间的停顿，无须按固定节拍说。观察是否切对方向；请分别比较正常、
稍快、稍慢、安静与当前底噪下的实际结果。未做真人实板验收。
