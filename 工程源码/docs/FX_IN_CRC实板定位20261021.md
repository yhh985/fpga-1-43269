# FX IN CRC 实板定位版

用户已确认使用 hx4s20_crc_skewfix.bit，原声可播放，但切音效无声且持续显示 FX IN CRC。
此前的时钟偏移修复没有解决本次实板故障，不能视为音效已完成实板验收。

## 本次新增什么

ACA新增独立于PCM解码器的管脚时钟比例测量，每次LRCK变化统计BCLK上升沿数，连续八个同类结果才更新。
两级同步后再检测边沿，容许边界相位带来的正负一个计数。输入停止约21ms后清除旧结果。
结果通过已有UART状态的保留位22:21发送到HX；原音频格式、CRC、DSP和四根音频线没有更改。

该版本用于定位传输失败，**不是宣称已经修复实板无声**。

## 怎么烧录

使用 `E:/anlo_project/liantiao/deliverable/audio_clock_probe_20261021` 的两份 `*_clock_probe.bit`。
两块都更新，保证新诊断字段能够发送和显示。
源码工程仍是 `E:/anlo_project/liantiao/development/audio_crc`，新包包含构建输入快照及校验记录。

进入MUSIC播放有声的WAV，长按ACA S3约一秒切音效。等约一秒记录完整提示。

| 提示 | 实际检测结果与下一步 |
|---|---|
| FX CLK LOW | 每个LRCK边沿间BCLK上升沿少于4个。两种时钟接反、管脚对应错误或信号异常均可能导致；不能直接断言接反。优先核对BCLK和LRCK两条线。 |
| FX SLOT 64 | 每个声道测到63～65个位时钟，当前接收协议需要32位。核对实际HX运行码流及位时钟来源。 |
| FX SLOT ERR | 连续检测到其他位数。检查时钟线对应关系、接触和异常跳变；该提示不能区分电气干扰与时钟源错误。 |
| FX IN CRC | 三根输入都有活动，且未被上面几类稳定位数异常拦下，但没有收到校验通过的完整立体声。继续定位DATA对应、数据相位或传输质量；不是音效计算成功。 |
| FX NO RET / FX OUT CRC | 去程已有效，再定位返回方向。 |
| FX ECHO / LOWPASS / TREMOLO | 返回数据已经连续通过校验，仍需实际听音确认。 |

## 当前约束对应接线

下面是已核对的工程约束与已有官方原理图记录；本次没有更换管脚。

| 信号 | HX接头 / FPGA球号 | ACA接头 / FPGA球号 |
|---|---|---|
| BCLK HX→ACA | J1-1 / D14 | P4-3 / F14 |
| LRCK HX→ACA | J1-2 / G11 | P4-4 / D16 |
| DATA HX→ACA | J1-3 / G12 | P4-5 / D14 |
| RETURN ACA→HX | J1-4 / F13 | P4-6 / E13 |
| 共地 | J2-12 | P4-12 |

P4-11不是共地。本次提示本身不证明连线错误，也不证明连线正确。若核对实物，请断电后操作，不要凭活动提示交换输出线。

## 验证与保存

独立RTL测试覆盖32、64、16、零位计数、计数溢出、短异常抑制、输入停止及恢复。
屏幕测试覆盖新增三种文字和已有十种文字。
实际双板顶层仿真保留原S2/S3、真实UART、HDMI PCM输入检查，并检查新字段经过UART到达HX；存储、PLL和加密HDMI仍使用测试桩。
旧音效DSP及串行往返回归结果按源码哈希检查。代码没有修改音效计算或串行PCM解码器。
