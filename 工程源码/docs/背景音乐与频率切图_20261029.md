# 背景音乐、频率变化切图与 OSD 消抖（2026-10-29）

## 操作

- ACA 原监听按键（key_monitor_n，FPGA B1）：按一次切换背景音乐开/关，默认关。沿用原接线，不新增引脚。实物丝印曾与旧说明不同，以 B1 对应按键为准。
- 手动图片模式：背景音乐开时播放当前 WAV，图片仍由手动控制。
- 自动图片模式：背景音乐开时播放当前 WAV，图片仍按原定时间间隔切换。
- 音乐模式：播放音乐；HX SW1 拨至 ON（低电平）启用随频率变化切图，OFF 禁用。不会改成固定定时切图。
- ACA S2 下一首，S3 短按上一首、长按切音效，S4 语音模式均保留。语音模式自动静音，退出后恢复背景开关状态；背景按键可在语音中预先改变退出后的选择。
- HX K4 长按仍暂停/恢复。暂停时音乐及切图暂停，恢复后重新建立频率基准。
- HX SW4：文字显示开关，输入需稳定约20ms，所有三层 OSD 在下一完整视频帧边界一起更新。
- 背景开关不关闭专用音乐模式的音乐；专用音乐模式退出到手动/自动后，才按背景开关状态决定是否继续播放。

## 实现

背景开关在ACA本地双触发同步、20ms消抖后以按下边沿翻转。用CRC保护的周期状态包 bit0 传递绝对状态（复用停用的演示字段），不发 toggle 指令，重传不会重复开关。HX要求在线及状态标记bit13有效；断线时手动/自动背景关闭，重新连接后按最新状态恢复。LED7仍表示通信在线。屏幕音乐状态及 TRACK 在背景模式也启用。

图片调度 audio_play_enable 与 WAV 读取的背景使能分开：背景不会把手动模式改成音乐切图模式，也不会关闭自动计时。复位默认背景关。

频率分析读取HX本地解码的SD音乐左声道，不分析麦克风。使用12位PCM、1024个有效样本窗口及带正负8死区的正向过零计数；按计数小于7、13、26和其余值划分四档，三个连续有效窗口确认档位变化，首次只建基准。每窗口至少一个样本的绝对值达到32才通过静音门限。两次切图请求至少相隔120视频帧（约2秒）。这是波形过零密度变化检测，不是FFT主频、BPM或节拍识别；复杂乐曲的谐波和噪声也会影响档位，相同档位不会固定周期切图。过渡期间保留一个待执行请求，退出音乐/关闭SW1/暂停时取消，不跨模式补发。

HX资源较紧，Goertzel版本和初版过零检测布局均超过器件MSlice容量，未发布失败码流。最终版在最高档26次处饱和计数，并只保存静音门限标记，消除不必要的最大值运算。此次布局使用4882个MSlice（上限4900）；最终布线后Setup WNS为0.377ns、Hold WNS为0.020ns，TNS均为0。ACA对应结果为0.253ns与0.091ns，TNS均为0。时序余量较小，后续修改需要重新编译验证。

主板实际按键回归与两帧视频回归、WAV解析、SD流、缩放回归另外记录在verification中。修正旧SD流测试对right_word的位选：当前打包PCM在[31:16]，旧测试仍取[23:8]导致假失败；硬件串行路径未因此改动。

仿真与内部时序不能代替实物接线、实际SD带宽、音乐切图观感和真实开关的验收。配套新码流需要更新两板；不会通过存储卡自动更新FPGA程序。
