# 双板最终展示整合工程

唯一工程根目录：本目录。整理日期：2026-10-30。

## 工程入口

- ACA420：`aca420/aca420_audio.al`，负责麦克风采集、离线语音识别、音效处理及按键。
- HX4S20：`hx4s20/contest_proj.al`，负责读卡、图片处理、音乐播放、显示和主控调度。
- 公共 RTL：`common/`。当前语音模型：`voice/model_ctc/`。
- 统一构建：`./build.ps1`；单板构建加 `-Board aca420` 或 `-Board hx4s20`。
- 换电脑或移动目录后，先执行 `python tools/prepare_showcase.py`，再在 TD 打开工程。
- 两板分别供电，UART 和数字音频按 `MUSIC_上板测试.md` 接线并共地。

## 本次整合的功能

1. 保留独立语音测试版的 CTC 模型及“下一张”低门槛识别策略、语音反馈、许可与 ACK。
   当前实际顶层使用 NEXT_ONLY=1；“上一张”语音不作为此版已开放功能。
2. SD/FAT32 的 BMP/WAV 读取、SDRAM 双帧缓存、下一张预加载和切歌。
3. 手动/自动/音乐播放、暂停、亮度/对比度/滤镜、图像缩放及转场。
4. ACA 背景音乐开关、音乐模式的频率档位变化切图及忙时请求合并保留。
5. HX→ACA→HX 的数字音乐音效链路，直通/半增益/低通/饱和失真。
6. SW4 消抖与整帧文字同步、OSD/状态显示和语音提示。

主开发版已包含测试版的识别逻辑与模型；逐文件对比后，保留主开发版新增的音乐、调度和频率逻辑。
没有将旧测试顶层覆盖到新功能上。合并取舍及两版差异记录见 `docs/integration/`。
测试版的模型加载检查和 SW4 测试合入 `aca420/sim/`、`sim/`；仿真替身不会进入 TD 硬件工程。

## 展示操作

- ACA B1 对应按键：背景音乐开/关；S2 下一首；S3 短按上一首，长按切音效；S4 切换语音模式。
- HX K4 短按切换图片/亮度/对比度/缩放操作页，长按暂停/继续。
- 音乐模式下 HX SW1 ON 启用频率变化切图；首次稳定频率只建立基准。
- SW3 关闭测试图；SW4 控制文字显示。开关方向以板上 ON 标记为准。
- 语音模式自动静音；退出后按背景音乐开关恢复。麦克风不会回放到扬声器。
